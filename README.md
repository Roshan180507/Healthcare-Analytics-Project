# Healthcare Analytics Project | SQL & Power BI

## 📌 Project Overview

This project focuses on analyzing healthcare data using SQL and Power BI. The objective is to explore patient demographics, doctor and facility performance, insurance coverage, payment patterns, and financial performance through data analysis and interactive dashboards.

## 🎯 Project Objectives

* Analyze patient demographics and age groups.
* Examine doctor and healthcare facility performance.
* Understand insurance coverage and payment patterns.
* Analyze total amounts, paid amounts, and insurance payments.
* Calculate and monitor the overall collection rate.
* Present key findings through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

* **SQL:** Data querying, validation, and analysis.
* **Power BI:** Interactive dashboard development and reporting.
* **Power Query:** Data cleaning and transformation.
* **DAX:** Measures and KPI calculations.

## 📊 Key Analysis Areas

1. **Patient Analysis** — Patient demographics and age-group distribution.
2. **Doctor & Facility Analysis** — Patient distribution across doctors and facilities.
3. **Insurance & Payment Analysis** — Insurance payments and payment patterns.
4. **Financial Overview** — Total amount, paid amount, and collection rate.

## 📈 Key Performance Indicator

**Overall Collection Rate**

Collection Rate = (Paid Amount ÷ Total Amount) × 100

This KPI measures the proportion of the total amount that has been paid.

## 📁 Project Files

* SQL query file — Healthcare data analysis queries.
* Power BI dashboard — Interactive healthcare analytics report.
